# How to MUKBANG

A mobile 3D mukbang game prototype made with Godot 4.

## Current milestone: shopping mall map
- Large shopping mall shell with a central atrium and skylight
- Food-court dining zones with tables and benches
- Eight vendor counters, menu boards, order kiosks and pickup counter
- Upper gallery, glass rails, entrance and decorative planters
- Procedural materials, architectural props and warm lighting

The map is currently a procedural blockout built from generated meshes and placeholder materials. Detailed food models, full movement and camera switching, sitting, ordering, and eating animations will be implemented in later milestones.

## Android build
Open **Actions → Build How to MUKBANG Android**, wait for the workflow to finish, then download the **How-to-MUKBANG-Android** artifact. You can also start a run manually with **Run workflow**.
